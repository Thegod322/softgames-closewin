# GuapikoClaw AI Skills & Tooling Archive

This directory contains copies of all AI skills, system instructions, and slash commands utilized across the 8 development sessions of **Operation Close Win**.

## 📂 Skills Catalog:

1. **[softgames-closewin](./softgames-closewin/SKILL.md)**:
   - The central living repository skill for the project.
   - Contains Tripeaks game rules, spatial overlap coordinate formulas, card modifier specifications (bomb, lock, key, zap), Monte Carlo heuristics, and multi-persona benchmark definitions.

2. **[guapiko-decompose-to-tasks](./guapiko-decompose-to-tasks/SKILL.md)**:
   - Instructs the AI agent on how to decompose complex technical specifications into atomic, testable, autonomous task files (`task_01`–`task_08`) with zero human management overhead.

3. **[guapiko-timeline-tracker](./guapiko-timeline-tracker/SKILL.md)**:
   - Automated transcript parser and chrono-engine.
   - Parses `transcript.jsonl`, calculates active AI time vs idle gaps, and generates interactive HTML timeline dashboards.

4. **[slash-commands.md](./slash-commands.md)**:
   - Reference guide for Antigravity slash commands (/learn, /browser, /grill-me, /btw).
